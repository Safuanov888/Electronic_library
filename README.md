Идея этого проекта возникла после разговора с заведующим кафедры моего ВУЗа. Ему понадобилась технология, которая может распределять текстовые внутривузовские материалы по темам. Так как это технология
напрямую связана с ML, и на момент написания этого текста мне необходимо выполнить курсовую работу по ML, то я решил убить 2 зайцев одним выстрелом. Здесь представлена моя электронная библиотека
научных статей в БД, рассортированных по своим темам с помощью LLM. Далее планируется использовать эту нейронку уже для университета.

Теперь этот проект выступает в роли моего диплома. Я почти польностью поменял подход, который применял ранее. Вот краткая сводка по файлам в папке "Диплом", чтобы можно было проще ориентироваться:
1) Project - это весь мой код в Pycharm, в котором присутствуют веб-интерфейс, интеграция с БД и написание классификатора;
2) Данные - clean_pdf.csv и embeddings_dataset.h5 использовать мной в основном для тестирования на 5 классах из 11, чтобы определить пригодность модели и данных. В первом файле очищенные от мусора pdf, а во втором полученнные с помощью RuBERT эмбеддинги чанков. В make_dataset.ipynb весь сырой код построения датасета для обучения модели, сделанный в среде Kaggle;
3) Обучение модели - включает в себя единственный ipynb файл с написанием моделей ML и DL, а также их валидацией.
