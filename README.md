Идея этого проекта возникла после разговора с заведующим кафедры моего ВУЗа. Ему понадобилась технология, которая может распределять текстовые внутривузовские материалы по темам. Так как это технология
напрямую связана с ML, и на момент написания этого текста мне необходимо выполнить курсовую работу по ML, то я решил убить 2 зайцев одним выстрелом. Здесь представлена моя электронная библиотека
научных статей в БД, рассортированных по своим темам с помощью LLM. Далее планируется использовать эту нейронку уже для университета.

Теперь этот проект выступает в роли моего диплома. Я почти польностью поменял подход, который применял ранее. Вот краткая сводка по файлам в папке "Диплом", чтобы можно было проще ориентироваться:
1) Project - это весь мой код в Pycharm, в котором присутствуют веб-интерфейс, интеграция с БД и написание классификатора;
2) Данные - clean_pdf.csv и embeddings_dataset.h5 использовать мной в основном для тестирования на 5 классах из 11, чтобы определить пригодность модели и данных. В первом файле очищенные от мусора pdf, а во втором полученнные с помощью RuBERT эмбеддинги чанков. В make_dataset.ipynb весь сырой код построения датасета для обучения модели, сделанный в среде Kaggle. Полный же обучающий датасет вместе с тестовыми данными я загружать сюда не стал, так как они достаточно большие; 
3) Обучение модели - включает в себя единственный ipynb файл с написанием моделей ML и DL, а также их валидацией.  

# 🧠 Основные методы и архитектура

1. **Предобработка PDF** – удаление мусора, английских слов и библиографии с помощью регулярных выражений.
2. **Сегментирование (чанкование)** – разбиение длинных документов на фрагменты по 512 токенов с перекрытием 50 токенов (`chonkie`).
3. **Извлечение признаков** – преобразование в эмбеддинг каждого чанка предобученной моделью `ruBERT-base-cased-conversational` размерность 768.
4. **Агрегация** – усреднение эмбеддингов чанков в единый вектор документа.
5. **Классификация** – полносвязная нейросеть `SimpleNet` предсказывает одну из 11 категорий.
6. **Сохранение результата** – метаданные записываются в реляционную базу данных PostgreSQL.

# 📊 Ключевые результаты

- **Средняя точность:** 93.34% на тестовой выборке  
- **Стабильность:** стандартное отклонение 0.17% (30 запусков)    
- **Нейросеть превосходит** Random Forest, LightGBM, XGBoost, CatBoost
